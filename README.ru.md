# SMENA

![SMENA — дашборд](docs/img/dashboard.png)

**Пассивный таймтрекер для Windows — время записывается само.**

*Documentation in English: [README.md](README.md)*

SMENA — локальный трекер для тех, кто забывает нажать «старт». Фоновый поллер
следит за активным окном и сам пишет рабочие блоки: нажимать нечего — забывать
негде. Таски с ключевыми словами ловят нужные окна автоматически; ручной
секундомер есть, но по желанию.

Всё остаётся на вашей машине: без облака, аккаунтов, телеметрии и скриншотов.
Данные лежат в `%APPDATA%\SMENA\` обычным JSON.

| | |
|---|---|
| | **Дашборд** — карточка «чем занят», донат и бары дня, таймлайн по таскам, проекты, отчёт недели с экспортом CSV / JSON / Markdown / HTML |
| ![Виджет](docs/img/widget.png) | **Виджет** — мини-таймер всегда под рукой: живые часы, секундомеры тасков, быстрый ввод, полоса дня. Один `Ctrl+Alt+U` |

## Как это работает

- **Пассивный захват** — поллер раз в 5 секунд сам записывает активное окно
  в блоки. Ручной таймер опционален; пока он идёт, автозахват на паузе
  (без двойного счёта).
- **Таски + ключевые слова** — у таска список ключей через запятую; заголовок
  окна важнее имени процесса, побеждает самое длинное совпадение. Нет совпадений
  → блок падает в **Unsorted**, ничего не теряется.
- **Детект простоя** — после N минут без ввода блок закрывается по времени
  последней активности. Опциональный промпт предложит записать пропуск по
  возвращению.
- **Инструменты разбора** — клик по блоку назначает таск, весь Unsorted сливается
  в один таск, сессии делятся, блоки правятся задним числом, Unsorted можно
  сбросить на ноль.

## Возможности

- **Дашборд**: карточка работы с чипами приложения/файла, статистика дня,
  гантт по таскам, свежие сессии, итоги недели с экспортом CSV / JSON /
  Markdown / HTML
- **Таймлайн**: полоса дня + лог активности с мультивыделением, схлопыванием
  и пакетным назначением
- **Сессии**: деление, заметки по блокам, правка даты/времени/таска, удаление
- **Отчёты**: недельная сетка (таски × дни) с группировкой по проектам
- **Темы**: тёмная SMENA плюс обличья Blender / Maya / Houdini / Nuke / DaVinci /
  Unreal / Substance (Settings → Appearance)
- **Цвета тасков**: акцентный цвет на таск — статистика, таймлайн и виджет
  следуют за ним
- **Виджет**: компактное окно с живыми часами, секундомерами тасков, быстрым
  вводом и полосой дня
- **Трей**: живой тултип статуса, пауза/продолжить, ручной таймер, выход

## Загрузка

Возьмите `SMENA_v*.zip` в разделе [Releases](../../releases), распакуйте,
запустите `SMENA.exe`. Сборка самодостаточная — Windows 10/11 x64, установка
рантаймов не нужна.

## Сборка из исходников

Нужен .NET 8 SDK (Windows, WPF):

```
dotnet build SMENA.sln
dotnet test  SMENA.sln
dotnet run --project SMENA_CS
```

## Хоткеи

| Клавиши | Действие |
|---|---|
| `Ctrl+Alt+S` | старт / стоп ручного секундомера (текущий или первый таск) |
| `Ctrl+Alt+P` | пауза / продолжить трекинг |
| `Ctrl+Alt+U` | показать / спрятать виджет |
